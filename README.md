# סמש

אימון חבטות טניס ופאדל מהטלפון.

- `index.html` – דף נחיתה. `start.html` – הרשמה. `pro.html` – מנוי שנתי (₪199).
- `js/account.js` – חשבון, 5 ניתוחים חינם, PRO. כאן מחברים בהמשך שרת וחברת סליקה (`PLAN.paymentUrl`).
- `app.html` – אפליקציית הטלפון: הטלפון הוא המחבט (חיישני תנועה), הילוך חוזר בתלת־ממד, חיבור למסך.
- `tv.html` – מסך הטלוויזיה/טאבלט: מגרש, מכונת כדורים, מחבט חי שמגיע מהטלפון (חיבור WebRTC דרך PeerJS).
- `analyze.html` – ניתוח וידאו: זיהוי 17 נקודות בגוף (MoveNet Lightning, רץ בדפדפן עם TensorFlow.js) והשוואה לטווחים לכל חבטה.
- `model/` – משקלי MoveNet (float16) בפורמט פשוט שהקוד ב־analyze.html קורא.

אתר סטטי, אין שלב build. פריסה: Vercel (Framework: Other).
